Kod Çıktıları ve Kod Yazma

1. Bölüm - Kodun Çıktısını Bulunuz

1. Aşağıdaki kodun çıktısı nedir? 
<?php
for( $i=2; $i<=10; $i+=2){
    echo $i."<br>";
}
?>
Cevap:
2, 4, 6, 8, 10
2. Aşağıdaki kodun çıktısı nedir? 
<?php
$toplam=0;
for($i=1; $i<=5; $i++){
    $toplam += $i;
}
echo $toplam;
?>
Cevap:
15
3. Aşağıdaki kodun çıktısı nedir? 
<?php
$i=1;
while($i<=5) {
    echo $i*2. "<br>";
    $i++;
}
?>
Cevap:
2, 4, 6, 8, 10
4. Aşağıdaki kodun çıktısı nedir? 
<?php
$dizi=array(10,20,30,40);
echo count($dizi);
echo "<br>";
echo max($dizi);
echo "<br>";
echo min($dizi);
?>
Cevap:
4
40
10
5. Aşağıdaki kodun çıktısı nedir? 
<?php
$dizi = array("Ali", "Ayşe", "Mehmet");
foreach($dizi as $deger) {
    echo $deger."<br>";

?>

Ayşe
Mehmet
6. Aşağıdaki kodun çıktısı nedir? 
<?php
for ($i=1; $i<=5; $i++){
    if($i==3){
        break;
    }
    echo $i."<br>";
}
?>
Cevap:
1, 2
(3'e gelince break döngüyü tamamen bitirir.)
7. Aşağıdaki kodun çıktısı nedir? 
<?php
for ($i=1; $i<=5; $i++){
    if($i==3){
        continue;
    }
    echo $i."<br>";
}
?>
Cevap:
1, 2, 4, 5
(continue, 3 sayısını atlar.)
8. Aşağıdaki kodun çıktısı nedir? 
<?php
function topla($a,$b){
    return $a+$b;
}
echo topla (10,15);
?>
Cevap:
25

2. Bölüm - Kod Yazma Soruları

9. PHP'de for döngüsü kullanarak 1'den 50'ye kadar olan çift sayıları ekrana yazdıran kodu yazınız.
Cevap: 
<?php
for($i=1; $i<=50; $i++){
    if($i%2==0) {
        echo $i."<br>";
    }
}
?>
10. 1'den 100'e kadar olan çift sayıların toplamını hesaplayıp ekrana yazdıran PHP kodunu yazınız.
Cevap: 
<?php
$toplam=0;
for($i=1; $i<=100; $i++){
    if($i%2==0){
        $toplam += $i;
    }
}
echo $toplam;
?>
Çıktı: 2550
11. PHP'de bir dizi oluşturunuz. Dizi içerisinde 5, 10, 15, 20 sayıları bulunsun. Foreach döngüsü kullanarak bütün elemanları ekrana yazdırınız.
Cevap: 
<?php
$dizi = array(5,10,15,20);
foreach($dizi as $deger) {
    echo $deger."<br>";
}
?>
12. İki sayı alan ve bu sayıların toplamını ekrana yazdıran topla() isimli bir fonksiyon yazınız.
Cevap: 
<?php
function topla($a,$b){
    echo $a+$b;
}
topla(5,3);
?>
Örnek çıktı: 8
13. 1'den 10'a kadar sayıları yazdıran, ancak 5 sayısına geldiğinde döngüyü tamamen durduran PHP kodunu yazınız. (Break kullanınız.)
Cevap: 
<?php
for($i=1; $i<=10; $i++) {
    if($i==5){
        break;
    }
    echo $i."<br>";
}
?>
Çıktı: 1, 2, 3, 4

4. Bölüm - Klasik Sorular

18. GET ve POST metotlarını karşılaştırınız. Aralarındaki iki farkı yazınız.
Cevap:
  • GET: Form bilgilerini URL adresinde göstererek gönderir. PHP'de $_GET kullanılır.
  • POST: Form bilgilerini URL adresinde göstermeden gönderir. PHP'de $_POST kullanılır.
  • Şifre gibi özel bilgilerin gönderilmesinde POST tercih edilir; ancak HTTPS de kullanılmalıdır.
19. Aşağıdaki PHP kodunda boş bırakılan yeri uygun ifadeyle tamamlayınız. 
<?php
function selam(){
    echo "Merhaba";
}
// Boşluk //
?>
Cevap: 
selam();
20. Aşağıdaki kodu inceleyiniz ve soruları cevaplayınız. 
<?php
$maas = 40000;
if ($maas<30000) {
    echo $maas + $maas * 0.10;
}
else{
    echo $maas + $maas * 0.05;
}
?>
a) Ekran çıktısı kaçtır?
b) Hangi koşul sağlanmıştır?
c) Maaşa yüzde kaç zam uygulanmıştır?
Cevap:
a) Ekran çıktısı: 42000
b) if($maas<30000) koşulu sağlanmamıştır; else bloğu çalışmıştır.
c) Maaşa %5 zam uygulanmıştır.
